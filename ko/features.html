widgets기능

보고, 고르고, 한 번에

미러쏙의 기능을 쓰임새별로 모았어요. Pro 표시가 있는 기능은 Pro에서 써요. 그룹·태그 정리는 무료, 그룹에 한 번에 명령하는 그룹 제어는 Pro예요.

보기·조작

grid_view무료 포함

기기 그리드

연결된 휴대폰 화면을 타일로 모아 보고, 번호·이름·연결 방식(USB/Wi‑Fi)·배터리로 구분해요.

open_in_full무료 포함

기기 상세·미러

한 대를 크게 띄워 마우스·키보드로 조작해요. 화질 프리셋과 폰 화면 끄고 미러링을 지원해요.

wifi무료 포함

USB·무선 연결

USB 디버깅만 켜면 연결돼요. Android 11 이상은 QR 코드로 무선 연결해요. 휴대폰에 앱을 설치할 필요 없어요.

folder_copy무료 포함

파일 전송·스크린샷

PC의 파일을 여러 대에 보내고, 화면을 바로 캡처해요.

videocamPro

화면 녹화

PC에서 휴대폰 화면을 그대로 녹화해요.

content_paste무료 포함

클립보드 동기화

PC에서 복사한 글자를 휴대폰에 붙여 넣어요. 설정에서 끌 수 있어요.

여러 대 한 번에

select_allPro

그룹 제어

그룹이나 여러 대를 골라 홈·뒤로·앱 실행 같은 명령을 한 번에 보내요. 무료 플랜에서는 한 대씩 조작해요.

syncPro

동기화 모드

기준 휴대폰 한 대의 터치·스와이프를 고른 휴대폰에 똑같이 보내요.

keyboardPro

문장 명령

한글·영문 문장을 여러 대에 한 번에 입력해요.

label무료 포함

기기 그룹·태그

기기에 이름을 붙이고 용도별 그룹·태그로 정리해요. 그룹에 명령을 한 번에 보내는 건 그룹 제어(Pro)예요.

자동화

account_treePro

워크플로

앱 실행·키·문장 명령·대기·캡처를 순서대로 묶어 한 번에 실행해요.

touch_appPro

매크로(확장 기능)

탭·스와이프를 녹화하고 편집해요. 화면 글자를 찾아 누르는 단계도 쓸 수 있어요.

replayPro

기기별 결과·다시 실행

기기마다 단계별 결과가 남고, 실패한 기기만 다시 실행해요.

storefrontPro

스토어 앱 시연·테스트 팩

테스트 앱 설치 → 실행 → 테스트 매크로를 기기마다 이어서 해요. 본인 또는 권한 있는 앱의 테스트·시연에만 사용.

도구

appsPro

앱 관리

APK를 여러 대에 설치하고, 앱을 정리해요.

terminalPro

ADB 고급

명령 도구로 여러 대에 같은 ADB 명령을 보내요.

troubleshoot무료 포함

연결 점검

케이블·권한·드라이버 문제를 순서대로 찾아 쉬운 말로 알려 줘요.

지금은 무료 베타예요

베타 기간에는 요금을 받지 않아요. 쓰면서 느끼신 점이나 문의는 문의 페이지 양식이나 메일로 보내 주세요.
