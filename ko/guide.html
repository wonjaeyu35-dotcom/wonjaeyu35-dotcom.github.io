처음부터 차근차근

설치부터 여러 대를 한 번에 다루기까지, 순서대로 따라 해 보세요.

  2. 휴대폰 준비하기
  3. 연결하기
  4. 여러 대 한 번에 다루기
  5. 자동화하기
  6. FAQ

1. 설치하기

  1. 다운로드 페이지에서 설치 파일을 내려받아 실행해요.
  2. Windows SmartScreen이 ‘알 수 없는 게시자’ 경고를 띄우면 ‘추가 정보’를 누른 다음 ‘실행’을 선택하세요.
  3. 사용권 계약에 동의하고 설치 위치를 확인해요. 관리자 권한은 필요 없어요.
  4. 설치가 끝나면 미러쏙을 열어요. 지금은 무료 베타라 요금을 받지 않아요.

2. 휴대폰 준비하기

  1. 설정 › 휴대전화 정보 › 소프트웨어 정보에서 빌드 번호를 7번 눌러 개발자 옵션을 열어요.
  2. 개발자 옵션에서 USB 디버깅을 켜요. 메뉴 이름은 제조사마다 조금 달라요.
  3. 휴대폰에 앱을 설치할 필요 없어요.

3. 연결하기

  1. USB: 데이터 전송이 되는 케이블로 연결하고 휴대폰의 ‘USB 디버깅 허용’을 눌러요.
  2. 무선: Android 11 이상은 ‘기기 추가 › 무선’에서 QR 코드를 찍어 연결해요.
  3. 연결이 안 되면 ‘연결 점검’이 원인을 순서대로 찾아 줘요.

4. 여러 대 한 번에 다루기

  1. 기기에 이름을 붙이고 그룹·태그로 정리해요(무료). 그리드에서 번호를 누르거나 끌어서 여러 대를 골라요.
  2. 아래 도구 막대로 홈·뒤로·앱 실행·문장 입력을 한 번에 보내요(그룹 제어, Pro).
  3. 기준 휴대폰의 조작을 따라 하게 하려면 동기화 모드를 켜요(Pro).

5. 자동화하기

  1. 자주 하는 순서는 워크플로로 묶어 버튼 하나로 다시 실행해요(Pro).
  2. 탭·스와이프는 매크로로 녹화해요. 매크로는 확장 기능으로 추가해서 써요(Pro).
  3. 스토어 앱 시연·테스트 팩은 본인 또는 권한 있는 앱의 테스트·시연에만 사용.

자주 묻는 질문

휴대폰이 목록에 나타나지 않아요
충전 전용 케이블이 아닌지, 휴대폰의 USB 디버깅이 켜져 있는지 확인해 주세요. 앱의 ‘연결 점검’이 원인을 순서대로 찾아 줘요.
‘USB 디버깅 허용’ 창이 뜨지 않아요
휴대폰 화면을 켠 상태에서 케이블을 다시 꽂아 보세요. 그래도 안 되면 개발자 옵션의 ‘USB 디버깅 권한 승인 취소’ 후 다시 연결해요.
몇 대까지 연결할 수 있나요?
무료 플랜은 2대, Pro는 대수를 제한하지 않아요. 실제로 쓸 수 있는 대수는 PC 성능과 USB 포트·허브 구성에 따라 달라져요.
휴대폰에 앱을 설치해야 하나요?
아니요. 휴대폰에 앱을 설치할 필요 없어요. USB 디버깅만 켜면 돼요.
iPhone도 되나요?
Android 휴대폰을 지원해요. iPhone은 지원하지 않아요.
무선이 자꾸 끊겨요
무선 기기가 3대 이상이면 끊김을 줄이려고 무선 기기만 화질을 자동으로 낮춰요. 공유기와 가까운 곳에서 쓰거나 USB 연결을 권장해요.
화면 데이터가 인터넷으로 나가나요?
아니요. 휴대폰 화면은 USB나 같은 네트워크로 PC에만 전달돼요. 개발자 서버로 보내지 않아요.
